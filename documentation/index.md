# Welcome to OpenTransit

</center>

Hey there! 👋

**OpenTransit** is a free and open-source alternative to the most popular messaging framework in .NET — **[MassTransit](https://github.com/MassTransit/MassTransit)**. It is a **community-maintained fork of MassTransit v8**, the last open-source version before it went commercial.
We started this project because we believe great tools should stay open and accessible to everyone.

However, there is a catch: OpenTransit will be supported only for **.NET 10+**. 

---

<center>

## What’s Happening Now

</center>

</br>

MassTransit v8 will continue to be supported until the end of **2026**, so we recommend using it for production in the meantime.

During this time, we’re:

- Diving deep into the codebase to fully understand the internals
- Writing clear, modern documentation that’s easy to follow
- Preparing the ground for future updates and improvements

Our main goal right now is to **learn, document, and collaborate** — not to rush.

Once MassTransit v8 reaches end of support, we’ll begin publishing our fork under the name OpenTransit and continue development. Until then, we recommend that you use MassTransit v8.
